# UX-аудит TabVault — 4 октября 2026

**Главная проблема — содержимому уделено меньше визуального внимания, чем управлению им.** Названия ссылок и коллекций теряются среди мелких подписей, многочисленных иконок и больших пустых промежутков. Некоторые действия также работают неожиданно.

Проверил интерфейс в Chromium на ширине **1440 и 390 px**: пустую библиотеку, три режима просмотра, поиск, редактирование, архив, скрытые вкладки, настройки и служебные страницы. Использовал тестовые данные; код не изменял. Работа расширения внутри Chrome и синхронизация с реальным сервером в проверку не входили.

Ниже — проблемы в порядке приоритета. **P1** мешает основному сценарию; **P2** затрудняет понимание и замедляет работу.

1. **P1 · На узком экране невозможно прочитать названия вкладок.**

   При ширине 390 px строка занимает 350 px, но заголовку остаётся **26 px**. Пользователь видит `Ag…`, `Ol…`, `M…`. Названия коллекций тоже обрезаются. Горизонтальной прокрутки нет, однако содержимое практически недоступно. [Скриншот](screenshots/ux-audit-2026-10-04/21-mobile-verified.png).

   **Изменить:** выделить названию основную ширину, разрешить две строки. Второстепенные действия собрать в меню `⋯`, метаданные перенести ниже. Аналогично разгрузить заголовки коллекций.

2. **P1 · Переключение на доску скрывает часть библиотеки.**

   В списке отображаются пять активных вкладок, на доске — только три: две вкладки без коллекции исчезают. Счётчик продолжает показывать `5 tabs`. Это создаёт впечатление потери данных. Поиск также учитывает результаты, которых на доске не видно. [Скриншот доски](screenshots/ux-audit-2026-10-04/05-board.png).

   **Изменить:** добавить карточку «Без коллекции». Переключение представления должно сохранять доступ ко всем тем же вкладкам; каждый результат поиска должен быть видимым или явно доступным.

3. **P1 · Мелкий текст недостаточно контрастен.**

   Управляющие подписи местами имеют размер **8–9 px**, дополнительно используются uppercase и разреженные буквы. Расчёт по цветам интерфейса дал:

   | Элемент                     | Контраст |
   | --------------------------- | -------: |
   | Домен под названием вкладки |   3,29:1 |
   | Подпись `Quick move`        |   2,59:1 |
   | Подсказка внутри поиска     |   2,51:1 |

   Для обычного текста ориентир WCAG AA — **4,5:1**. [Требование W3C](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html).

   **Изменить:** начать с названий 15–16 px, вторичного текста 13–14 px и более тёмных подписей. Убрать uppercase у фильтров, статусов и основных действий. Это предлагаемые размеры, а не требование стандарта.

4. **P1 · Закрытая мобильная навигация перехватывает клавиатурный фокус.**

   После кнопки открытия меню клавиша Tab переводит фокус на невидимые `Close navigation`, `All Tabs`, `Archive`, `Hidden`, расположенные за левым краем экрана.

   **Изменить:** исключить закрытую панель из фокуса. При открытии переводить фокус внутрь, при закрытии возвращать на кнопку меню. Иконку кубиков заменить привычной иконкой навигации.

5. **P2 · Пустая библиотека выглядит как неудачный поиск.**

   При первом открытии без данных и без запроса показано `No links matched that query` и предложение попробовать другой поиск. Это неверно объясняет состояние и не помогает начать работу. При этом доступна очистка дубликатов. [Скриншот](screenshots/ux-audit-2026-10-04/01-empty.png).

   **Изменить:** разделить состояния «ещё ничего не сохранено», «коллекция пуста» и «ничего не найдено». Для первого показать конкретный следующий шаг: импорт библиотеки или сохранение вкладок через расширение.

6. **P2 · Иконки и клики обещают другое действие.**

   Подтверждены следующие несоответствия:

   | Элемент                    | Фактическое действие              |
   | -------------------------- | --------------------------------- |
   | Корзина у активной вкладки | Архивирование                     |
   | `⋯` у вкладки              | Сразу открывает редактирование    |
   | Тег `#product`             | Открывает управление всеми тегами |
   | Favicon на доске           | Переключает на список коллекции   |
   | Галочка в строке           | Отмечает просмотренность          |

   Пользователю приходится запоминать эти особенности.

   **Изменить:** использовать значок архива для архивирования, карандаш для редактирования, многоточие для меню. Тег должен фильтровать библиотеку, favicon — открывать ссылку. Статус просмотра нужно явно объяснить: сейчас его легко принять за выбор строки.

7. **P2 · Большие пустоты мешают сканировать список.**

   В стандартном режиме строка имеет высоту **96 px**, а после каждой раскрытой группы дополнительно зарезервировано **96 px пустого пространства** для перетаскивания. На тестовой библиотеке всего из пяти активных вкладок уже требуется прокрутка. [Скриншот](screenshots/ux-audit-2026-10-04/02-standard.png).

   **Изменить:** сократить постоянные промежутки между группами; место для вставки показывать при перетаскивании, сохранив стабильность расположения. Стандартную строку сделать компактнее, но сохранить читаемый домен и теги.

8. **P2 · Доска плохо объясняет содержимое коллекций.**

   Внутри карточек видны только favicon. Несколько страниц одного сайта неразличимы; названия самих коллекций тесно зажаты между кнопками даже на desktop. Пользователь должен открывать коллекции по очереди, чтобы понять, что внутри.

   **Изменить:** показывать несколько названий вкладок и остаток `Ещё N`. Название коллекции разместить отдельной строкой, редкие действия убрать в меню. Основное действие подписать «Посмотреть вкладки», а открытие всех ссылок сделать отдельным.

9. **P2 · Служебные страницы требуют знания внутренней модели.**

   В дедупликации пользователь видит `OLDEST_CREATED`, `SURVIVOR_VALUE`, `CONCAT`, идентификаторы записей и JSON. В Dashboard — `local_only`; в редакторе — `Explicit value`, `Use default`. Это затрудняет оценку результата перед действием. [Скриншот дедупликации](screenshots/ux-audit-2026-10-04/14-deduplicate.png).

   **Изменить:** использовать понятные формулировки: «Оставить самую старую», «Объединить заметки», «Сохранено в этом браузере». Перед объединением показать названия, коллекции и изменения в формате «было → станет». Технические данные оставить в раскрываемых подробностях.

10. **P2 · Действия синхронизации не соответствуют локальному режиму.**

    В локальном режиме Dashboard предлагает заметную кнопку `Sync now`; при проверке нажатие не дало видимого результата. `Refresh library` сообщает об обязательном подключении сервера только после клика. [Скриншот](screenshots/ux-audit-2026-10-04/11-dashboard.png).

    **Изменить:** показывать состояние «Сохранено в этом браузере» и действие «Подключить сервер». Синхронизацию предлагать после настройки подключения, с понятным результатом выполнения.

**Первую итерацию я бы ограничил четырьмя изменениями:** исправить мобильную строку, вернуть вкладки без коллекции на доску, увеличить читаемость текста и привести иконки к фактическим действиям. Тёплую палитру и общий спокойный характер интерфейса можно сохранить.

## Первая итерация — реализовано в 0.9.0

- На узком экране названия вкладок занимают до двух строк; действия вынесены на отдельную строку. Заголовки коллекций получили больше места.
- Доска показывает виртуальную коллекцию `[Unassigned]`. Её можно просматривать, искать в ней и использовать как назначение перетаскивания; отдельная запись коллекции не сохраняется.
- Увеличены и затемнены подписи рабочего экрана, домены, фильтры и счётчики. Основной цвет кнопок затемнён для читаемости светлого текста.
- Архивирование использует значок архива, редактирование — карандаш. Статус просмотра подписан `Viewed`. Нажатие на тег включает точный фильтр `#tag`, favicon доски открывает ссылку.
- Закрытая мобильная навигация исключена из фокуса; открытие фокусирует кнопку закрытия, Escape возвращает фокус на кнопку меню.
- Первое открытие пустой библиотеки объясняет состояние и предлагает импорт. Очистка дубликатов не предлагается, если видимых вкладок меньше двух.

Остаются следующие итерации: уменьшение постоянных промежутков для перетаскивания без нарушения стабильности групп; текстовые превью ссылок на доске; упрощение служебных страниц и действий синхронизации. Мобильные действия пока размещены отдельной строкой, без дополнительного меню.

### Коррекция выравнивания и плотности

По обратной связи заголовки списка и доски приведены к фиксированным колонкам: цвет → название → тип коллекции. Для пользовательских категорий и виртуальной коллекции сохранены те же размеры ячеек, поэтому названия и индикаторы не смещаются. Действия карточки собраны в нижнем ряду; убраны минимальная высота 210 px и растягивание до высоты соседа. На тестовых данных карточка с одним рядом ссылок занимает 155 px. Кнопка создания коллекции также уплотнена. Обновлённые скриншоты выше используют локальные fallback-иконки; проверены ширины 320, 390, 768 и 1440 px.
