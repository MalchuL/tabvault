# Supatabs Interaction Reference

Supatabs publicly describes directional collection shortcuts for tabs **left of the active tab**, **right of the active tab**, **all tabs**, and **a single tab**. Its documentation also warns that its selection-based save path does not preserve existing Chrome tab groups, while directional options should be used when group preservation matters.

TabVault adopts the directional interaction concept for a small, explicit popup. Unlike Supatabs, TabVault labels every control with a title and text label, previews the number of tabs selected, supports Chrome’s selected-tab state as an explicit selection action, saves to the TabVault library, and closes tabs only after the save result is confirmed.

Sources: [Supatabs documentation](https://docs.supatabs.com/) and the [Supatabs Chrome Web Store listing](https://chromewebstore.google.com/detail/supatabs-tab-manager/icbcnjlaegndjabnjbaeihnnmidbfigk).
