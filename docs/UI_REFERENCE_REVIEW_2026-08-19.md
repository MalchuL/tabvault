# Unified All Tabs Reference Review

The supplied reference establishes a **single workspace with multiple representations**, not separate collection destinations. The workspace title remains stable while a compact view toggle changes how the same grouped data is read.

| Reference pattern                         | TabVault interpretation                                                                                                                 |
| ----------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| One persistent workspace title            | **All Tabs** becomes the only active-library destination. Inbox and individual collections stop being sidebar navigation destinations.  |
| Group cards                               | A **Group board** view shows each collection as a summary card with previewed links and collection actions.                             |
| Grouped data table                        | The existing flat/collapsible library view becomes the **List view**, retaining per-tab controls, selection, search, and drag-and-drop. |
| Archive as a peer destination             | Archive remains a separate lifecycle destination because it has distinct recovery and deletion rules.                                   |
| Small view toggle in the workspace header | The All Tabs header controls the active representation rather than moving users into a separate Collections page.                       |

The retained TabVault visual system remains the warm Signal Library system. The reference contributes information architecture and interaction hierarchy, not its dark visual treatment.
